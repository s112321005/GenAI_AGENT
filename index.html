Itinerary

東京 Relaxed 3 日遊 ➔

點擊檢視包含淺草寺、明治神宮、SHIBUYA SKY、teamLab Planets 與晴空塔的完整詳細行程規畫頁面。
📍 經典景點 (Spots)
景點 / 歷史文化

淺草寺 (Sensoji Temple)

東京都內最古老的寺廟，著名的雷門紅燈籠與仲見世通商店街。

景點 / 神社參拜

明治神宮 (Meiji Jingu)

位於澀谷區的廣闊綠洲，獻給明治天皇與昭憲皇太后的神社。

景點 / 高空觀景

SHIBUYA SKY

澀谷 Scramble Square 頂樓的高空露天展望台，可俯瞰十字路口全景。

景點 / 沉浸式藝術

teamLab Planets

位於豐洲的身臨其境數位藝術展覽，體驗身心融入藝術作品的感受。

景點 / 地標塔樓

東京晴空塔 (Tokyo Skytree)

世界最高塔式建築之一，具備展望台、商場與天象館的大型複合設施。

🍜 美食地圖 (Food)
美食 / 鰻魚日料

福田家 (Fukudaya)

歷史悠久的老字號鰻魚與傳統日式料理名店。

美食 / 串燒烤肉

伊勢廣 (Isehiro Yakitori)

京橋著名的炭火燒鳥老店，以道地醬汁與新鮮雞肉串燒聞名。

美食 / 蕎麥麵

神田まつや (Kanda Matsuya)

東京傳統手工蕎麥麵代表老店，展現純粹的日式麵食風味。

美食 / 日式咖哩

南海咖哩 (Rice Curry Manten)

神保町深受學生與上班族喜愛的大份量經典日式黑咖哩名店。

美食 / 文字燒

月島文字燒 もへじ (Monja Moheji)

月島文字燒街人氣名店，以高湯底與新鮮海鮮文字燒著稱。
